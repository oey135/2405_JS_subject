2.  내장 함수

    ② indexOf(찾고자 하는 문자열) :
    - 찾고자 하는 문자열의 **첫 인덱스** 반환
    - 찾고자 하는 값이 없다면 **-1** 반환
    - indexOf(대상 문자열, 검색 시작 위치)

    ③ lastIndexOf(찾고자 하는 문자열):
    - 뒤에서 부터 문자열을 찾아 첫 인덱스 반환

    ④ **slice(시작위치, 종료위치) :** 문자열을 시작위치부터 종료위치-1까지 잘라내기
    - 종료위치 생략 -> 끝까지, 시작과 종료에 음수가 올 수 있다.
    - 접근 방식이 유연하다.
    - 가장 권장하는 방식이다.

    ⑤ substring(시작위치, 종료위치) : 문자열을 시작위치부터 종료위치-1까지 잘라내기
    - 시작과 종료 위치에 음수가 오는 경우 기본적으로 0으로 처리하거나, 오동작 할 수 있다.

    ⑥ substr(시작위치, 잘라낼 길이) : 문자열을 길이만큼 잘라내기
    - 명확하게 길이를 알고 있을 경우 매우 유용

    \*\*\*substring vs substr vs slice\*\*
    - sclice : 가장 유연하고 현대적인 메소드, 음수처리가 가능 - (ES6 이후 매우 추천)
    - substring : slice와 유사하지만 인덱스가 음인 경우 처리가 다르다
    - substr : 인덱스가 아닌 글자 수를 기준으로 하지만 현재 웹표준으로 권장하지 않는다.

    ⑦ replace(str1, str2): 문자열1을 문자열2로 교체하는 함수

    ⑧ \*\*\*\*toUpperCase() : 대문자로 변환
    - 사용자입력에 따른 유효성 체크에 반드시 사용됨. (프론트가 해줘야해요)

    ⑨ \*\*\*\*toLowerCase() : 소문자로 변환
    - 사용자입력에 따른 유효성 체크에 반드시 사용됨. (프론트로 해줘야해요)

    - 제품번호 대문자, 데이터베이스 대문자 => 제품번호를 조회해보자.
    - 사용자는 다양하게 입력하게 되므로.. 입력된 내용을 대(소)문자로 변환하면 된다.
    - 사용자입력에 따른 유효성 체크에 반드시 사용됨.

    ⑩ concate() : 문자열을 하나로 합치기, 합치려는 문자열의 갯수에 제한이 없다.

    ⑪ trim() : 문자열의 앞, 뒤 공백을 제거

    ⑫ \*\*\*\*padStart(길이, 문자열):
    - 특정 문자를 앞에 채운다. 현업에서 가장 많이 사용하고, 중요하다.
    - ES5부터 등장, 날짜 양식 - 04-23이지만 누군가가 4-23으로 입력 시 사용

    ⑬ padEnd(맞출 길이, 채울 글자) :

    padEnd : (문자열 전체길이, 뒤에 채울 문자열)
    => 거의 사용하지 않는다.

    ⑭ \*\*\*charAt(index) : 인덱스에 해당하는 문자 1개 반환

    ⑮ charCodeAt(index) : 인덱스에 맞는 유니코드 값을 반환

    \*\*\*\*\*\*\*\*\*\*\*split(구분자) : 파라미터로 전달받은 문자열로 변수에 할당된 문자를 나눠서 *배열*로 반환

    \*\*\*\*startWith() : 전달받은 문자열로 시작하는지 여부를 체크해서 boolean으로 리턴

    \*\*\*\*endsWith() : 전달받은 문자열로 끝나는지 여부를 체크해서 boolean값으로 반환
